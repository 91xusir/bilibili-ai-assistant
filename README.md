# Bilibili AI 视频助手

Bilibili 视频页 AI 助手浏览器扩展（Chrome MV3）：AI 视频总结 + 可点击时间轴 + 广告片段识别与跳过。默认使用 **Kimi 网页版**（免 API Key），也可配置任意 **OpenAI 兼容接口**。

## 功能

- **视频总结**：AI 按章节生成总结（总览 + 章节卡片），流式输出、边生成边显示。
- **时间轴**：全部字幕按播放位置高亮，自动跟随滚动（可关闭）；广告片段红行标记。
- **广告识别与跳过**：
  - 自动跳过开启：播放到广告片段自动 seek 到片段尾，并弹出提示；
  - 自动跳过关闭：播放到广告片段时在面板内提示「疑似检测到广告，是否跳过？」，3 秒不操作自动关闭；
  - 广告识别可与总结合并为一次 AI 请求（广告提示词前置，流式优先返回广告结果）。
- **点击行为**（设置可选）：跳转（默认，点击卡片/字幕行跳转到播放位置）或复制（总结复制章节内容，时间轴复制字幕行）；**点击时间徽章始终跳转**。
- **缓存**：字幕（IndexedDB）与总结/广告结果（chrome.storage）按视频缓存，可设保留时长（0 = 永久），支持在选项页按视频查看与勾选清理。
- **导出**：面板右下角统一悬浮按钮，一键导出视频总结为 Markdown。
- **手动触发**：自动功能全部可关闭；关闭后用面板右下角 ⟳ 生成总结、时间轴页「识别广告」按钮单独识别。
- **暗色模式**：跟随 B 站深浅色（`html.night-mode`）；面板宽度跟随视频选集区域。

## 安装（开发者模式）

1. 安装 [Bun](https://bun.sh)，在项目目录执行 `bun install && bun run build`；
2. 打开 `chrome://extensions`，开启右上角「开发者模式」；
3. 「加载已解压的扩展程序」选择本项目 `dist/` 目录；
4. 打开任意 B 站视频页，右侧栏顶部出现面板。

## 使用

- **面板**：位于右侧栏弹幕列表上方，两个标签页「视频总结 / 时间轴」。
- **右下角悬浮按钮**：⟳ 重新生成（生成中自动禁用）；⤓ 导出菜单（无总结时置灰）。
- **工具栏图标弹窗（Popup）**：功能开关快捷入口（自动总结 / 识别广告 / 自动跳过广告 / 点击文本 / 缓存）+「完整设置 →」。
- **选项页（Options）**：AI 服务商配置（Kimi 授权 / OpenAI 接口、模型列表、思考等级、测试连接）、任务开关、缓存设置、缓存管理（按视频勾选清理，同时删除字幕与总结/广告）。

## AI 配置

- **Kimi 网页版（默认）**：免 API Key，复用浏览器 kimi.com 登录态。首次使用建议先在选项页点「重新获取授权」；每次任务创建独立会话，完成后自动删除，不污染聊天列表。
- **OpenAI 兼容接口**：填写 Base URL / API Key / 模型名；「获取列表」拉取上游 `GET /models`；思考等级不设置则按服务商协议关闭思考模式。所有请求经后台 Service Worker 发出（支持真正的流式响应）。

## 开发

```bash
bun install        # 安装依赖
bun run build      # 构建到 dist/ (content.js + service-worker.js + popup.js/options.js + html/css)
bun run typecheck  # TypeScript 全量类型检查
bun test           # bun 单元测试 (tests/)
```
